# Location imagery

Staff can attach a site photo or open an optional Street View preview for a saved location. The app sends the location coordinates to Google when a staff member opens the preview.

1. Enable Maps Embed API in Google Cloud.
2. Restrict the browser key to Maps Embed API and the exact origins where you run the app.
3. Set `GOOGLE_MAPS_EMBED_KEY` in the launcher shell and restart the app.
4. Open a client location, choose **Set map position**, then choose **Street View**.

The [Google Maps Embed documentation](https://developers.google.com/maps/documentation/embed/embedding-map) covers key restrictions and supported embed modes. Use the Directions link or attach a site photo when Street View coverage is missing.

The fictional equipment records link to manufacturer literature from Carrier, Delta, and Bosch. Add your own equipment photos through the workspace.
